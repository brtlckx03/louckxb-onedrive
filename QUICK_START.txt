PROBLEM: "Samsung phone not detected"
CAUSE: Mac doesn't auto-mount Android phones like USB drives

SOLUTION: Download Android File Transfer
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Install Android File Transfer
   URL: https://www.android.com/filetransfer/
   ✓ Download for Mac
   ✓ Install in /Applications
   ✓ Launch the app

STEP 2: Prepare Your Samsung Phone
   ✓ Connect via USB cable
   ✓ Unlock the phone
   ✓ Tap "Allow" when prompted
   ✓ Settings → Change USB mode to "File Transfer"
     (NOT "Charging Only")

STEP 3: Run Diagnostics
   $ cd /Users/louckxb/Documents/wd-brtlckx/louckxb-onedrive
   $ ./diagnose-phone.sh

   This will show:
   ✓ Connected volumes
   ✓ DCIM/Pictures directories
   ✓ USB devices
   ✓ The phone mount path!

STEP 4: Run the App
   $ javac src/Phone.java src/ReadFilesOnPhone.java
   $ java -cp src ReadFilesOnPhone

   If auto-detect still fails:
   → Choose Option 2: Manual Mount Path
   → Enter the path from diagnose-phone.sh output

STEP 5: Filter and net.lckx.onedrive.Upload
   ✓ Enter date range (e.g., 1/03/2026 till 3/03/2026)
   ✓ View photos from that period
   ✓ Choose to upload to OneDrive
