⏱️  5 MINUTE SETUP:

1. EXPORT PHOTOS
   ├─ Open OpenMTP app (already installed)
   ├─ Click your phone
   ├─ Navigate to: DCIM/Camera
   ├─ Select all: Cmd+A
   ├─ Right-click → Export
   ├─ Save to: ~/Downloads/phone-photos/
   └─ Wait for export to complete

2. RUN APP
   $ cd /Users/louckxb/Documents/wd-brtlckx/louckxb-onedrive
   $ java -cp src ReadFilesOnPhone

3. CHOOSE OPTION 2
   When asked for path, choose:
   → Option 2: Manual Mount Path
   → Enter: ~/Downloads/phone-photos/

4. FILTER & UPLOAD
   ├─ Enter dates: 1/03/2026 till 3/03/2026
   ├─ Review photos
   └─ net.lckx.onedrive.Upload to OneDrive

TROUBLESHOOTING:

Problem: Photos not exporting from OpenMTP
Solution: Make sure phone is connected & unlocked in OpenMTP

Problem: Can't find export folder
Solution: Use full path: /Users/louckxb/Downloads/phone-photos/
          (not just ~/Downloads/phone-photos/)

Problem: App says folder empty
Solution: Double-check export completed
          Try: ls ~/Downloads/phone-photos/
